# Как начать пользоваться sh1n VPN

1. Распакуйте весь архив. Файл **sh1n VPN.exe** и папка **core** должны остаться рядом.
2. Откройте **Перенос**. Вставьте ссылки из буфера, выберите файл или перетащите его в окно. Для вставленного текста нажмите **Импортировать**.
3. Выберите профиль и режим, нажмите **Подключить**.
   - **Прокси**: SOCKS5 и HTTP на 127.0.0.1. Адреса с портами появятся в карточке. Укажите их в нужной программе. Системные маршруты и прокси Windows не меняются. Порты доступны другим локальным процессам.
   - **VPN / TUN**: [Xray TUN и Wintun](https://xtls.github.io/en/config/inbounds/tun.html) для системного трафика. Требует запуска приложения от имени администратора. Клиент не включает TUN поверх работающего Happ или другого процесса Xray, и не завершает их сам.

## Перенос из Happ и v2rayN

- **Happ**: скопируйте открытую HTTPS-ссылку подписки либо воспользуйтесь [штатным экспортом ссылки или JSON](https://www.happ.su/main/faq/share-configuration) для доступного профиля. Скрытые и зашифрованные профили не извлекаются.
- **v2rayN / v2rayNG**: выделите нужные профили и скопируйте или экспортируйте ссылки. Поддерживаются стандартные ссылки и распространённые [внутренние ссылки v2rayN](https://github.com/2dust/v2rayN/wiki/Description-of-subscription) для поддерживаемых протоколов. Внутренние группы, цепочки и специальные расширения не переносятся.
- **Xray JSON**: импортируются outbounds в исходном порядке, без inbounds, routing, балансировщиков и DNS. Сложная конфигурация после переноса может работать иначе. Поддерживается один объект или массив профилей.
- **WireGuard**: поддерживаются ссылки wireguard:// из v2rayN и клиентские файлы .conf с адресами и peer-настройками. Системные директивы wg-quick (например, PostUp) не выполняются и приводят к отказу в импорте. Для DNS в файле указываются IP-адреса.
- **Hysteria2**: стандартные ссылки, TLS с проверкой и Salamander; расширения port hopping и Realm в ссылках пока не поддерживаются.

HTTPS-импорт создаёт локальный снимок; автообновления нет. URL не сохраняется. Запрос идёт по текущему маршруту Windows к указанному провайдеру, без следования перенаправлениям. HTTP 4xx/5xx означает, что провайдер не отдал подписку в этом запросе.

## Экспорт и хранение

Для одного профиля: **Подключение → Действия → Экспорт выбранного**. Для всего списка: **Перенос → Экспортировать все**. JSON переносится между компьютерами, но **содержит ключи доступа в открытом виде** — не публикуйте его и не прикладывайте к GitHub Issues.

Рабочая копия шифруется Windows DPAPI для текущего пользователя и хранится в **%LOCALAPPDATA%\sh1n VPN\profiles.dpapi**. При переходе со старой сборки существующее хранилище Velum читается как резервный источник; новый клиент старый файл не меняет.

**Ctrl+I** — импорт. **Ctrl+F** — поиск по профилям. Можно выбрать тему на странице **Темы**.

## Границы беты

Нужны собственные серверы или подписка. Клиент не включает VPN-сервис. OpenVPN, IKEv2, TUIC и AnyTLS в этой сборке не поддерживаются. Интерфейс для мобильных платформ, Linux и macOS пока не выпущен.
