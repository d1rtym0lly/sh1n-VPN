# sh1n VPN · Beta 01

Первая публичная бета: нативный Windows-клиент Xray для собственных прокси и VPN-профилей.

- Новый интерфейс: три экрана, увеличенные подписи, поиск, горячие клавиши и десять тем.
- Перенос из Happ и v2rayN через доступные подписки, ссылки и файлы; добавлены WireGuard и Hysteria2.
- Экспорт выбранного профиля или всей библиотеки в Xray JSON. Рабочая копия защищена DPAPI, экспорт — нет.
- Режимы SOCKS5/HTTP и TUN; режим прокси не меняет настройки Windows.

**Установка:** распакуйте Windows x64 ZIP целиком и откройте **sh1n VPN.exe**. Рядом должна остаться папка **core**. Файл .sha256 предназначен для проверки архива. **Превью MP4** показывает интерфейс с вымышленными профилями.

Пакет не подписан. Скрытые настройки провайдера и неподдерживаемые VPN-протоколы не импортируются. Системный TUN требует администратора и не запускается поверх Happ. Подробнее — в README и START-HERE.md внутри архива.
